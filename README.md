# PIXELCRAFT - Python Image Editor

A simple desktop image editing application built using Python, Tkinter, and Pillow.

## Features
- Open images from local storage
- Grayscale filter
- Blur filter
- Sharpen filter
- Edge detection
- Brightness adjustment
- Reset edited image
- Save edited images locally
- Colorful graphical user interface

## Technologies Used
- Python
- Tkinter
- Pillow

## Installation

```bash
pip install -r requirements.txt

***********
